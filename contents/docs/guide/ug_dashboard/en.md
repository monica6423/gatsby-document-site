## Dashboard
-  Open Signaal and click on the dashboard on the left to enter the dashboard page
   ![](../../img/doc/dashboard1.png)

At the top, you can see the sending and reply status of various message alerts.

-   Scrolling the value summary below, you can see each alarm chart, and can be filtered according to requirements.
   ![](../../img/doc/dashboard2.png)
-In the report below, you can see the alarm sending time, alarm message statistics, and whether to respond.
   ![](../../img/doc/dashboard3.png)
-   Click More to view events
   ![](../../img/doc/dashboard4.png)
-   Below you can see the SMS usage and License detail.
   ![](../../img/doc/dashboard5.png)
