## Signaal system requirements

-  Operating system: Windows Server 2012 R2 and above
-  CPU: 1 core @ 1.4GHz and above
-  RAM: 2GB or more
-  Hard Disk: 1GB or more free space
-  Network card: above 100Mbps
-  Browser: Chrome, Firefox and Safari

## Client Requirements

-  CPU above i3 series
-  2GB or more RAM
-  Browser:
   * Chrome current version
   * Current version of Firefox


## Supported SMS platform

-  Chunghwa Telecom (CHT)
-  Taiwan Big Brother (TWM)
-  Asia Pacific Telecom (APTG)
-  Signaal SMS
-  SMS Station

## Supported communication applications

-  LINE
-  Facebook Messenger
-  Telegram
-  Viber
-  WhatsApp
-  WeChat
