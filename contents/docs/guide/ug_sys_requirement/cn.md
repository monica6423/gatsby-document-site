## Signaal系统需求

- 作业系统：Windows Server 2012 R2 以上
- CPU：1核心 @ 1.4GHz 以上
- RAM：2GB 以上
- 硬碟：1GB 以上 可用空间
- 网卡：100Mbps 以上
- 浏览器：Chrome、Firefox及Safari

## 用户端需求

- i3系列 以上 CPU
- 2GB 以上 记忆体
- 浏览器：
  * Chrome 目前版本
  * Firefox 目前版本


## 支援的简讯平台

- 亚太电信（APTG）
