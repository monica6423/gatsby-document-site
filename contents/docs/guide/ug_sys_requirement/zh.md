## Signaal系統需求

- 作業系統：Windows Server 2012 R2 以上
- CPU：1核心 @ 1.4GHz 以上
- RAM：2GB 以上
- 硬碟：1GB 以上 可用空間
- 網卡：100Mbps 以上
- 瀏覽器：Chrome、Firefox及Safari

## 用戶端需求

- i3系列 以上 CPU
- 2GB 以上 記憶體
- 瀏覽器：
  * Chrome 目前版本
  * Firefox 目前版本


## 支援的簡訊平台

- 中華電信（CHT）
- 台灣大哥大（TWM）
- 亞太電信（APTG）
- Signaal SMS
- SMS Station

## 支援的通訊應用程式

- LINE
- Facebook Messenger
- Telegram
- Viber
- WhatsApp
- WeChat

## 支援的其他告警方式
- 電話語音
