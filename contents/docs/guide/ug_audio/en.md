## Set up
Click on Service Integration on the left to view the list of service items
![](../../img/doc/integration_dir.png)

Tap the voice notification to enter the settings

![](../../img/doc/voice1.png)

Please enter the country code and mobile phone number and click Add.

-   Please edit the voice list to send a voice message

![](../../img/doc/voice2.png)

-   Edit voice message

![](../../img/doc/voice3.png)

Please enter the content of the message you want to send, and the system will automatically convert it into a voice file (200 characters).
