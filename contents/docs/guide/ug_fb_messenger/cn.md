## 取得 Signaal ID

在Signaal使用者设定中，每一种通讯软体都需要使用者填写资讯，才能与通讯软体进行连结，而每一种通讯软体都有各自不同的连结码，输入正确的连结码，Signaal即可进行讯息传送。

本篇将会进行设定操作，教导如何取得通讯软体连结码，与通讯软体进行连结。

以下操作需将对应的Signaal bot加入好友。

### 方法一：快速设定

请参考下列任一方法将官方帐号加入好友中
  * ID:\@whisprer
  * Link: [Signaal(Whisprer)](https://www.facebook.com/whisprer)

移动至官方帐号聊天视窗，输入:`/token KT**VB` (注：服务整合功能查看)

管理者在Signaal使用者设定画面即可看到User已被新增。

### 方法二：手动设定

请参考下列任一方法将官方帐号加入好友中
  * ID:\@whisprer
  * Link: [Signaal(Whisprer)](https://www.facebook.com/whisprer)

移动至官方帐号聊天视窗，输入:`/token`即可取得Facebook Messenger连结码

选择新增至新使用者或者现有使用者，输入或选择使用者名称，并将连结码填写至ID栏位。

![](../../img/doc/facebook1.png)

完毕后，点选新增即可。
