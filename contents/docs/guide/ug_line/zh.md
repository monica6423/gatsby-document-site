## 取得 Signaal ID

在Signaal使用者設定中，每一種通訊軟體都需要使用者填寫資訊，才能與通訊軟體進行連結，而每一種通訊軟體都有各自不同的連結碼，輸入正確的連結碼，Signaal即可進行訊息傳送。

本篇將會進行設定操作，教導如何取得通訊軟體連結碼，與通訊軟體進行連結。以下操作需將對應的Signaal bot加入好友。

### 方法一：快速設定

透過以下方式加入LINE好友
  * bot id : `@sxt7315p`
  * QR code
![https://qr-official.line.me/M/OuV1\_70A5h.png](../../img/doc/line1.png)

請使用者開啟手機通訊軟體，至官方帳號輸入`/token KT**VB`(註：服務整合功能查看)。

管理者在Signaal使用者設定畫面即可看到User已被新增。

![](../../img/doc/line2.png)

### 方法二：手動設定

透過以下方式加入LINE好友
  * bot id : `@sxt7315p`
  * QR code
![https://qr-official.line.me/M/OuV1\_70A5h.png](../../img/doc/line3.png)

移動至官方帳號聊天視窗，輸入:`/token`即可取得LINE連結碼

選擇新增至新使用者或者現有使用者，輸入或選擇使用者名稱，並將連結碼填寫至ID欄位。

![](../../img/doc/line4.png)

完畢後，點選新增即可。
