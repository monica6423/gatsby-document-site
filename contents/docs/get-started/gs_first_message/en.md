## Step1: Log in as an administrator
![](../../img/doc/exam_1_login.png)

## Step2: Click on the service integration on the left to view the list of service items
![](../../img/doc/exam_2_sitebar.png)

## Step3: Select any sending message platform
* LINE, Messenger, Telegram, Viber, WeChat continue Step4
* WhatsApp, SMS continue to Step6

![](../../img/doc/exam_3_integration.png)

## Step4: Refer to the page description to join the official account (take LINE as an example)
![](../../img/doc/exam_4_addfriend.png)

## Step5: Refer to quick add, enter `/token XXXXXX` to create notification information (take LINE as an example)
* Continue to Step7

![](../../img/doc/exam_5_token.png)

## Step6: Refer to the page description to add information (take SMS as an example)
![](../../img/doc/exam_6_addinfo.png)

## Step7: Click on the user on the left to view the user list
![](../../img/doc/exam_7_sitebar.png)

## Step8: Click on your user (added by Step5/Step6)
![](../../img/doc/exam_8_users.png)

## Step9: Go to the test below to select the test sending platform (take LINE as an example), and click the test button
![](../../img/doc/exam_9_test.png)

## Step10: Finish, and check the first test message
![](../../img/doc/exam_10_getmsg.png)
